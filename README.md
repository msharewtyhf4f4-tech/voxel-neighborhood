# Voxel Neighborhood

اصنع لعبة مدينة ثلاثية الأبعاد (3D) بأسلوب المكعبات (Voxel style) تعمل على متصفح الجوال. تحتوي على شارع رئيسي طويل وعلى جانبيه منازل صغيرة مرقمة بأسماء المشتركين. أضف شخصية لاعب بزي خليجي/عربي يمشي في الشارع، مع عصا تحكم دائرية في أسفل اليسار للحركة وزر (قفز) في أسفل اليمين. أضف في الأعلى شريطاً يعرض عدد سكان المدينة والنقاط، وأيقونات جانبية لاستدعاء سيارة والدردشة."
